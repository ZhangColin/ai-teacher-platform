## 设计说明

### P1 假设与处理方式

**AI工具模块**：
- **P1-001 代码块语言标识的标准化处理**：实现时处理，支持大小写不敏感和常见别名。具体处理逻辑由开发决定，在实现和测试间不断打磨。
- **P1-002 会话命名的边界情况**：UI 定长度，保证美观。具体长度由前端决定，主要不能破坏美观。
- **P1-003 工具分类的标准化**：工具配置包含 `category` 字段（字符串），后端加载时按 category 聚合生成分类结构。如果多个工具使用相同的 category 名称，自动归为一类。

**后台管理系统**：
- **P1-004 图标自动推荐算法**：采用简单关键词匹配算法（从名称和描述中提取关键词），匹配预定义的关键词到图标的映射表。用户可以随时修改推荐的图标。后续可优化为AI推荐或机器学习模型。
- **P1-005 文件上传进度显示**：当前简单实现，前端显示loading状态。文件上传成功后关闭loading并显示成功提示。后续可优化为实时进度条（显示百分比）或分片上传+断点续传。
- **P1-006 HTML文件安全验证**：当前只进行基础的文件类型和大小验证（.html文件，< 5MB/10MB）。前端使用iframe沙箱渲染，防止XSS攻击。后续可扩展为HTML内容安全扫描（检测恶意脚本）或人工审核流程。

**文档管理模块（AI素养课）**：
- **P1-007 文档内容存储方式**：采用文件系统存储（与作品管理保持一致），Markdown文件存储到 `backend/static/course_docs/{doc_id}/content.md`。数据库只存储元数据（标题、摘要、文件路径、排序等）。这样可以减轻数据库压力，便于版本管理和备份。
- **P1-008 目录层级深度**：数据库设计支持无限层级（通过 `parent_id` 自引用实现），UI层不限制。建议使用时不超过3-4级，保持良好的用户体验。
- **P1-009 章节目录提取**：前端渲染时从Markdown提取标题生成章节目录（可选功能）。如果实现简单（< 30分钟）就加上，如果实现复杂就跳过。可以使用 `marked` 库的 Heading Token 提取。
- **P1-010 下载功能复用**：优先复用现有Markdown工具的下载功能（Markdown/Word/PDF）。如果复用难度大，可以简化为只支持Markdown下载。不要大改原有功能，避免破坏现有系统。如有疑问，开发找产品经理讨论。
- **P1-011 排序操作实现**：由开发决定具体实现方式（上下箭头、拖拽、手动输入order等），不强求。推荐使用上下箭头（与后台管理系统保持一致，实现简单）。
- **P1-012 图片处理**：当前迭代不实现图床功能。Markdown中的图片使用外部链接（CDN）或手动上传到static目录（相对路径）。如果图片显示有问题，修改Markdown文档，而非修改系统。后续迭代再考虑图床功能。

### P2 后续迭代考虑

**AI工具模块**：
- **P2-001 代码块嵌套解析优化**：当前仅解析最外层代码块，嵌套代码块的处理留待后续迭代优化。
- **P2-002 历史对话列表预览**：当前不显示预览，后续迭代可考虑显示首条或最后一条消息预览。
- **P2-003 配置验证规则的详细细化**：当前基础验证（必填字段检查），详细验证规则留待后续迭代细化。
- **P2-004 会话标题 AI 生成**：当前基于第一条消息的前 N 个字符，后续迭代可扩展为 AI 生成标题。
- **P2-005 成果物存储优化**：当前使用数据库存储，如果大文本内容查询需求增加，可考虑使用对象存储或文件系统。

**后台管理系统**：
- **P2-006 后台管理操作日志**：记录管理员的所有操作历史（创建、编辑、删除、上传、权限变更等），支持操作审计和回溯。
- **P2-007 细粒度权限控制**：定义不同角色（超级管理员、内容管理员、运营管理员等），为不同角色分配不同的管理权限。支持基于资源的权限控制（用户管理、工具管理、作品管理分别授权）。
- **P2-008 批量操作功能**：支持批量删除工具/作品、批量修改分类、批量导入导出等操作，提升运营效率。
- **P2-009 拖拽排序功能**：使用拖拽库（如vue-draggable）替代上下箭头，提供更直观的排序体验。可同时支持拖拽和箭头两种方式。
- **P2-010 数据导入导出**：支持导出工具/作品配置为JSON或Excel，批量导入配置数据，便于数据迁移和备份。
- **P2-011 HTML资源文件管理**：支持上传HTML相关的CSS、JS、图片等资源文件，提供在线资源管理器。支持打包上传（ZIP格式）。
- **P2-012 HTML文件版本管理**：记录HTML文件的历史版本，支持版本回滚和版本对比，便于内容管理和问题修复。
- **P2-013 后台管理仪表盘**：显示系统概览（用户数、工具数、作品数等）、关键指标（工具使用量、作品浏览量等）和数据可视化图表。
- **P2-014 后台管理搜索功能**：支持按名称搜索用户/工具/作品，支持高级搜索（按分类、类型、可见性等组合筛选）。
