## 需求概述

### 背景
当前系统提供了"AI工具"、"教研员"、"常用工具"、"作品展示"四个模块。用户需要一个集中的文档学习平台，用于存储和展示系统化的课程文档，方便用户系统化学习AI素养相关知识。

### 目标
建立"AI素养课"模块（前台模块名称，可能会调整），为用户提供一个文档阅读和学习平台。所有文档均为Markdown格式，用户可以在线阅读、预览和下载。

### 核心定位
- **AI工具** - 基于大模型对话的生成类工具（文生文、图生成等）
- **教研员** - 教学研究与备课评课辅助工具
- **常用工具** - 日常工作中的实用小工具集合（编辑、转换、计算等）
- **作品展示** - 优秀HTML作品的展示平台（创意展示、灵感参考）
- **AI素养课** - 系统化的课程文档展示和学习平台（文档阅读、知识学习）

---

## 用户价值

### 目标用户
- 教师、教研员
- 学习AI素养课程的学生
- 自学AI知识的学习者
- 所有需要系统化学习AI相关知识的用户

### 核心价值
1. **系统化学习** - 结构化组织的课程文档，方便用户按顺序学习
2. **便捷阅读** - 在线阅读，无需下载，随时随地学习
3. **内容下载** - 支持下载为多种格式（Markdown/Word/PDF），方便离线学习
4. **清晰导航** - 多级目录结构，清晰的文档组织，易于查找和定位

## 功能范围

### 本次迭代包含

#### ✅ 前台展示功能
1. **主页面布局** - 左侧目录 + 中间文件列表 + 右侧文档内容
2. **多级目录** - 支持多级目录结构，美观展示
3. **文件列表** - 展示标题和摘要
4. **文档阅读** - Markdown渲染展示
5. **文档下载** - 复用现有Markdown工具的下载功能（Markdown/Word/PDF）
6. **文档导航** - 上一篇/下一篇切换
7. **章节目录** - 文档内章节目录（如果技术可行）

#### ✅ 后台管理功能

2. **文档上传** - 上传Markdown文件，填写标题和摘要
3. **文档管理** - 修改文档信息（标题、摘要）、删除文档
4. **文档排序** - 调整文档在列表中的显示顺序

#### ❌ 延后功能

- 评论、讨论功能
- 阅读进度记录
- 文档搜索功能
- 阅读统计（浏览次数、下载次数）
- 用户收藏功能
- 文档标签功能

- 文档长度限制

## 用户故事

### 故事1：浏览目录和文件
**作为** 一名用户  
**我想要** 在AI素养课页面看到清晰的目录结构和文档列表  
**以便于** 快速找到我想学习的内容

**验收标准**：
- 用户点击顶部导航"AI素养课"，进入模块主页面
- 页面左侧显示多级目录树，美观清晰（参考Element UI多级菜单效果）
- 页面初始状态：只显示目录，中间文件列表为空，右侧文档内容区为空
- 目录支持展开和折叠
- 用户点击某个目录后，中间文件列表显示该目录下的所有文档
- 文件列表中每个文档显示标题和摘要

---

### 故事2：阅读文档
**作为** 一名用户  
**我想要** 点击文件列表中的文档后在右侧阅读文档内容  
**以便于** 学习课程知识

**验收标准**：
- 用户点击文件列表中的某个文档后，右侧文档内容区显示该文档的Markdown渲染内容
- Markdown渲染效果与系统现有的Markdown预览效果一致
- 文档内容区顶部显示下载按钮，点击后弹出格式选择（Markdown/Word/PDF）
- 下载功能与现有Markdown工具的下载功能完全一致
- 文档内容区提供上一篇/下一篇按钮（如果存在上一篇或下一篇）
- 点击上一篇/下一篇后，自动切换到对应文档并更新文件列表的选中状态

---

### 故事3：文档导航
**作为** 一名用户  
**我想要** 在阅读文档时能够快速跳转到文档的不同章节  
**以便于** 快速定位到我需要的内容

**验收标准**：
- 如果文档内包含多个标题（章节），右侧显示文档内章节目录（如果技术可行）
- 章节目录显示文档中的所有标题（h1、h2、h3等）
- 点击章节目录中的某个标题后，文档内容区滚动到对应位置
- 章节目录跟随文档滚动高亮当前章节

**说明**：此功能为增强功能，如果技术实现复杂，可以在第二版实现。

---

### 故事4：管理目录（后台）
**作为** 一名管理员  
**我想要** 在系统后台管理文档的目录结构  
**以便于** 组织和维护课程文档的结构

**验收标准**：
- 管理员在系统后台"文档管理"菜单中，可以看到目录管理页面
- 管理员可以创建新目录，填写目录名称
- 管理员可以创建多级目录（子目录）
- 管理员可以编辑目录名称
- 管理员可以删除目录（删除前检查是否有文档，如果有文档需要提示并阻止删除）
- 管理员可以调整目录的显示顺序（实现方式由开发决定，如拖拽、上下箭头等）

---

### 故事5：上传和管理文档（后台）
**作为** 一名管理员  
**我想要** 在系统后台上传和管理文档  
**以便于** 维护课程内容

**验收标准**：
- 管理员在"文档管理"页面可以上传新文档
- 上传时填写文档标题、文档摘要，并上传Markdown文件（.md格式）
- 上传时选择文档所属的目录
- 上传成功后，文档保存到系统固定文件夹中，数据库记录文档信息
- 管理员可以修改已上传文档的标题和摘要
- 管理员可以删除文档，删除时弹出二次确认提示（"确定删除《XXX》？此操作不可恢复"）
- 管理员可以调整同一目录下文档的显示顺序（实现方式由开发决定）

## 功能详述

### 5.1 前台主页面布局

**页面结构**：
```
┌────────────────────────────────────────────────────────────┐
│  顶部导航栏（AI工具、教研员、常用工具、作品展示、AI素养课）   │
├────────────┬──────────────┬────────────────────────────────┤
│            │              │                                │
│  目录区    │  文件列表区   │   文档内容区                    │
│  （左侧）   │  （中间）     │   （右侧）                      │
│            │              │                                │
│  多级目录   │  - 标题1      │   [文档Markdown渲染]           │
│  ├─分类1   │    摘要...    │                                │
│  │ ├─子分类│  - 标题2      │   [下载按钮]                    │
│  │ └─子分类│    摘要...    │   [上一篇/下一篇]              │
│  └─分类2   │              │   [章节目录]                    │
│            │              │                                │
└────────────┴──────────────┴────────────────────────────────┘
```

**布局说明**：
- **目录区（左侧）**：宽度适中，支持折叠展开，类似Element UI多级菜单效果
- **文件列表区（中间）**：宽度适中，显示标题和摘要
- **文档内容区（右侧）**：主要内容区，占据大部分空间

**初始状态**：
- 页面加载时，只显示目录树
- 文件列表区为空（显示空白或提示"请选择左侧目录"）
- 文档内容区为空（显示空白或提示"请选择文档进行阅读"）

---

### 5.2 目录区（左侧）

**功能描述**：
- 显示多级目录结构
- 支持任意层级（理论上无限级，实际使用中不会太深）
- 目录可以展开和折叠
- 点击目录后，中间文件列表区显示该目录下的文档

**交互细节**：
- 目录项前有展开/折叠图标（如果有子目录）
- 点击目录项后，该目录高亮显示（当前选中状态）
- 点击展开/折叠图标，展开或折叠子目录
- 目录顺序由后台管理员配置

**样式参考**：
- 类似Element UI的多级菜单（el-menu）效果
- 美观、清晰、易于导航

---

### 5.3 文件列表区（中间）

**功能描述**：
- 显示当前选中目录下的所有文档
- 每个文档显示标题和摘要
- 点击文档后，右侧显示文档内容

**交互细节**：
- 文档列表项显示：
  - 文档标题（加粗或突出显示）
  - 文档摘要（灰色文字，1-2行，超出显示省略号）
- 点击文档后，该文档项高亮显示（当前选中状态）
- 文档顺序由后台管理员配置

**边界情况**：
- 如果当前目录下没有文档，列表为空（显示空白）

---

### 5.4 文档内容区（右侧）

**功能描述**：
- 显示选中文档的Markdown渲染内容
- 提供下载功能（Markdown/Word/PDF）
- 提供上一篇/下一篇导航
- 提供文档内章节目录（如果技术可行）

**交互细节**：

**1. Markdown渲染**
- 渲染效果与系统现有Markdown预览完全一致
- 支持标题、列表、表格、代码块、引用、链接等Markdown语法
- 支持数学公式渲染（如果系统支持）
- Markdown中的图片：如果图片路径正确且文件存在，正常显示；如果无法显示，显示占位符或不显示（暂不处理）

**2. 下载功能**
- 下载按钮位置：文档内容区右上角
- 点击下载按钮，弹出格式选择菜单：Markdown / Word / PDF
- 下载功能完全复用现有Markdown工具的下载功能
- 下载文件名：使用文档标题作为文件名

**3. 上一篇/下一篇导航**
- 位置：文档内容区底部或顶部（由开发决定）
- 逻辑：
  - 根据当前目录下文档的顺序，判断是否有上一篇和下一篇
  - 如果有上一篇，显示"上一篇"按钮，点击后切换到上一篇文档
  - 如果有下一篇，显示"下一篇"按钮，点击后切换到下一篇文档
  - 如果没有上一篇或下一篇，对应按钮禁用或不显示
- 切换效果：
  - 右侧文档内容区更新为新文档内容
  - 中间文件列表区的选中状态更新为新文档

**4. 文档内章节目录（增强功能）**
- 如果文档中包含多个标题（h1、h2、h3等），显示章节目录
- 章节目录位置：文档内容区右侧侧边栏或顶部（由开发决定）
- 章节目录显示文档中的所有标题，形成树状结构
- 点击章节目录中的某个标题，文档内容区滚动到对应位置
- 章节目录跟随文档滚动，高亮当前阅读的章节

**说明**：章节目录为增强功能，如果实现复杂度高，可以在第二版实现。

**边界情况**：
- 如果没有选中任何文档，内容区为空（显示空白）

---

### 5.5 后台管理功能

**功能入口**：
- 系统后台已有后台管理系统（如作品管理等）
- 在后台导航中新增"文档管理"菜单
- 点击后进入文档管理页面

**功能模块**：

#### 5.5.1 目录管理

**页面布局**：
- 显示目录树结构（类似前台的目录展示）
- 每个目录项旁边有操作按钮：编辑、删除

**创建目录**：
- 提供"创建目录"按钮
- 点击后弹出表单：
  - 目录名称（必填）
  - 父目录（可选，选择后创建为子目录）
- 确认后创建目录

**编辑目录**：
- 点击目录项的编辑按钮
- 弹出表单，可以修改目录名称
- 确认后保存修改

**删除目录**：
- 点击目录项的删除按钮
- 检查该目录下是否有文档或子目录
- 如果有文档或子目录，弹出提示："该目录下有内容，无法删除。请先清空该目录。"
- 如果没有内容，弹出二次确认："确定删除目录《XXX》？"
- 确认后删除目录

**调整目录顺序**：
- 实现方式由开发决定（如拖拽、上下箭头、手动输入顺序号等）
- 调整后立即保存

---

#### 5.5.2 文档管理

**页面布局**：
- 显示文档列表（按目录分组或全部列表）
- 每个文档项显示：标题、摘要、所属目录、操作按钮（编辑、删除）

**上传文档**：
- 提供"上传文档"按钮
- 点击后弹出表单：
  - 文档标题（必填）
  - 文档摘要（必填）
  - 所属目录（必填，下拉选择）
  - Markdown文件（必填，上传.md文件）
- 确认后上传文档
- 文档保存到系统固定文件夹中，数据库记录文档信息

**编辑文档信息**：
- 点击文档项的编辑按钮
- 弹出表单，可以修改文档标题、摘要、所属目录
- 不支持修改文档内容（如果需要修改内容，删除后重新上传）
- 确认后保存修改

**删除文档**：
- 点击文档项的删除按钮
- 弹出二次确认："确定删除《XXX》？此操作不可恢复。"
- 确认后删除文档（删除数据库记录和文件）

**调整文档顺序**：
- 实现方式由开发决定（如拖拽、上下箭头、手动输入顺序号等）
- 调整后立即保存

---

### 5.6 边界情况和异常处理

**目录为空**：
- 如果系统中还没有创建任何目录，前台显示"暂无内容"提示

**文档列表为空**：
- 如果当前目录下没有文档，文件列表区为空（显示空白）

**没有选中文档**：
- 如果用户还没有点击任何文档，文档内容区为空（显示空白）

**Markdown渲染失败**：
- 如果文档内容无法正常渲染，显示错误提示："文档加载失败，请稍后重试"

**Markdown中的图片**：
- 暂不考虑图片处理（不实现图床功能）
- 如果Markdown中引用了图片，且图片路径正确，正常显示
- 如果图片路径不正确或文件不存在，不显示图片（不报错）
- 图片处理在后续迭代中考虑

**文档内容过长**：
- 暂不限制文档长度
- 如果文档过长，正常渲染和滚动显示

**文件上传失败**：
- 如果上传文件失败（网络错误、文件格式错误等），显示错误提示："上传失败，请检查文件格式或稍后重试"

## 非功能性需求

### 性能要求
- 文档列表加载时间 < 1秒
- Markdown渲染时间 < 2秒（中等长度文档）
- 目录树展开/折叠响应时间 < 200ms

### 兼容性要求
- 支持主流浏览器：Chrome、Edge、Safari、Firefox（最新版本）
- 暂不要求移动端适配

### 可维护性要求
- 文档文件统一存储在固定文件夹中，便于备份和迁移
- 数据库记录文档信息（标题、摘要、文件路径、所属目录、排序等）
- 目录结构数据存储在数据库中
