## 需求概述

### 背景
当前系统提供了"AI工具"（基于大模型对话的生成类工具）和"教研员"（教学研究辅助工具）两个模块。用户反馈希望有一个集中的地方，提供日常工作中常用的实用小工具，如Markdown编辑器、格式转换工具等。

### 目标
建立"常用工具"模块，为用户提供一个便捷的工具集合平台，支持两种类型的工具：
1. **系统内置工具** - 由我们开发的功能性工具
2. **HTML工具** - 上传的独立HTML页面工具

### 核心定位
- **AI工具** - 基于大模型对话的生成类工具（文生文、图生成等）
- **教研员** - 教学研究与备课评课辅助工具
- **常用工具** - 日常工作中的实用小工具集合（编辑、转换、计算等）

---

## 用户价值

### 目标用户
- 教师、教研员
- 办公人员
- 内容创作者
- 所有需要快速使用实用工具的用户

### 核心价值
1. **便捷性** - 无需安装，打开即用，用完即走
2. **集中性** - 所有常用工具集中在一个平台，无需四处寻找
3. **专业性** - 工具功能专注、简洁、高效
4. **扩展性** - 支持上传自定义HTML工具，满足个性化需求

## 用户故事

### 故事1：浏览工具
**作为** 一名用户  
**我想要** 在常用工具页面浏览所有可用的工具  
**以便于** 快速找到我需要的工具

**验收标准**：
- 用户点击顶部导航"常用工具"，进入工具卡片页
- 工具按分类组织展示
- 每个工具显示名称、描述和图标
- 如果某个分类下没有工具，则不显示该分类

---

### 故事2：使用内置工具
**作为** 一名用户  
**我想要** 使用Markdown编辑器编辑文档  
**以便于** 快速创建和导出Markdown格式的内容

**验收标准**：
- 用户点击"Markdown编辑器"卡片，进入编辑器页面
- 左侧是Markdown编辑区，右侧是实时预览区
- 预览区支持Markdown语法和数学公式渲染
- 用户可以下载为Markdown、Word或PDF文件
- 页面提供"返回"按钮，返回工具卡片页
- 工具不保存内容，关闭或刷新后内容丢失（临时工具）

---

### 故事3：使用HTML工具
**作为** 一名用户  
**我想要** 使用上传的HTML工具  
**以便于** 完成特定的任务

**验收标准**：
- 用户点击HTML工具卡片，进入工具运行页面
- HTML内容在沙箱环境中运行（安全隔离）
- HTML页面占满工具详情页区域
- 页面提供"全屏"按钮，点击后进入全屏模式
- 全屏模式下提供"退出全屏"按钮
- 页面提供"返回"按钮，返回工具卡片页

## 功能详述

### 1. 工具卡片页

#### 页面结构
```
+--------------------------------------------------+
|  顶部导航栏（AI工具 | 教研员 | 常用工具 | ...） |
+--------------------------------------------------+
|                                                  |
|  【分类1名称】                                    |
|  +----------+  +----------+  +----------+       |
|  | 图标     |  | 图标     |  | 图标     |       |
|  | 工具名称 |  | 工具名称 |  | 工具名称 |       |
|  | 工具描述 |  | 工具描述 |  | 工具描述 |       |
|  +----------+  +----------+  +----------+       |
|                                                  |
|  【分类2名称】                                    |
|  +----------+  +----------+                     |
|  | 图标     |  | 图标     |                     |
|  | 工具名称 |  | 工具名称 |                     |
|  | 工具描述 |  | 工具描述 |                     |
|  +----------+  +----------+                     |
|                                                  |
+--------------------------------------------------+
```

#### 交互行为
- **展示逻辑**：
  - 按分类组织工具，分类按预设顺序排列
  - 分类下的工具按预设顺序排列
  - 如果某个分类下没有工具，则不显示该分类
  
- **点击行为**：
  - 用户点击工具卡片，跳转到对应的工具详情页

- **视觉设计**：
  - 卡片布局、间距、hover效果等细节由前端团队设计
  - 要求简洁、大方、美观

---

### 2. 工具详情页

#### 2.1 内置工具（以Markdown编辑器为例）

**页面结构**：
```
+--------------------------------------------------+
|  [返回] Markdown编辑器                           |
+--------------------------------------------------+
|                    |                             |
|  【编辑区】         |  【预览区】                  |
|                    |                             |
|  Markdown文本编辑  |  实时预览                    |
|                    |  - Markdown格式渲染         |
|                    |  - 数学公式渲染（KaTeX）     |
|                    |                             |
|                    |  [下载 Markdown] [Word] [PDF]|
|                    |                             |
+--------------------------------------------------+
```

**功能要求**：
- **编辑区**：
  - 提供文本编辑框，支持Markdown语法输入
  - 技术参考：可调研行业内成熟的Markdown编辑器方案
  
- **预览区**：
  - 实时渲染Markdown内容
  - 支持数学公式渲染（与AI工具聊天预览保持一致）
  - 渲染效果与AI工具预览面板保持一致
  
- **下载功能**：
  - 支持下载为Markdown、Word、PDF格式
  - 复用AI工具聊天的下载功能
  
- **临时性**：
  - 不保存用户编辑内容
  - 刷新或关闭页面后内容丢失
  - 无需历史记录功能

#### 2.2 HTML工具

**页面结构**：
```
+--------------------------------------------------+
|  [返回] 工具名称                   [全屏]         |
+--------------------------------------------------+
|                                                  |
|  +--------------------------------------------+  |
|  |                                            |  |
|  |        HTML工具内容（沙箱运行）             |  |
|  |                                            |  |
|  +--------------------------------------------+  |
|                                                  |
+--------------------------------------------------+

【全屏模式】
+--------------------------------------------------+
|                                      [退出全屏]  |
|  +--------------------------------------------+  |
|  |                                            |  |
|  |        HTML工具内容（沙箱运行）             |  |
|  |                                            |  |
|  +--------------------------------------------+  |
+--------------------------------------------------+
```

**功能要求**：
- **沙箱运行**：
  - HTML在iframe沙箱中运行，与AI工具预览面板的实现方式一致
  - 确保安全隔离，防止恶意代码影响主系统
  
- **布局**：
  - HTML页面占满工具详情页的内容区域
  
- **全屏功能**：
  - 提供"全屏"按钮，点击后HTML页面进入浏览器全屏模式
  - 全屏模式下提供"退出全屏"按钮
  
- **导航**：
  - 提供"返回"按钮，返回工具卡片页

---

### 3. 首个内置工具：Markdown编辑器

#### 功能定位
一个简洁的临时Markdown编辑工具，适用于快速编辑和导出文档。

#### 核心特性
1. **即开即用** - 无需登录状态，无需保存，打开即可使用
2. **实时预览** - 左侧编辑，右侧实时渲染
3. **格式支持** - 支持标准Markdown语法和数学公式（LaTeX）
4. **多格式导出** - 支持Markdown、Word、PDF格式下载

#### 使用场景
- 快速编辑Markdown文档
- 临时记录笔记或想法
- 预览Markdown效果
- 导出为其他格式

## 非功能性需求

### 安全性
- HTML工具必须在沙箱环境中运行，防止XSS攻击
- HTML工具无法访问用户Cookie、LocalStorage等敏感信息
- HTML工具无法访问主系统的DOM结构

### 可扩展性
- 数据结构设计需支持未来的后台管理功能（上传、编辑、删除）
- 支持两种工具类型的扩展（内置工具、HTML工具）
- 分类结构支持未来的动态管理

### 可维护性
- 内置工具和HTML工具的渲染逻辑复用现有代码（AI工具预览面板）
- 代码结构清晰，便于后续添加新的内置工具
