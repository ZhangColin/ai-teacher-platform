# 常用工具创意清单

**文档版本**: v1.0  
**创建日期**: 2026-01-09  
**文档说明**: 本文档列出常用工具模块的潜在内置工具创意，供后续迭代参考

---

## 📋 分类说明

本清单按功能领域分类，每个工具都是独立的单页面应用，适合作为"常用工具"模块的内置工具或上传的HTML工具。

---

## 📝 文档编辑类

### ✅ Markdown编辑器（本次迭代已实现）
- **功能**：左侧编辑Markdown，右侧实时预览，支持下载为Markdown/Word/PDF
- **使用场景**：快速编辑文档、写笔记、预览效果
- **实现方式**：内置工具
- **状态**：已实现

### 富文本编辑器
- **功能**：所见即所得的富文本编辑，支持格式化、插入图片、表格等
- **使用场景**：编辑公告、制作简单的宣传页
- **技术参考**：Quill、TinyMCE、CKEditor
- **建议优先级**：P2

### 文本对比工具（Diff）
- **功能**：左右两栏输入文本，高亮显示差异部分
- **使用场景**：对比文档版本、检查修改内容
- **技术参考**：diff库（如jsdiff）
- **建议优先级**：P2

### 字数统计器
- **功能**：输入文本，实时统计字数、词数、字符数、段落数
- **使用场景**：控制文章篇幅、检查作业字数
- **建议优先级**：P3

### Markdown转HTML
- **功能**：输入Markdown，转换为HTML代码
- **使用场景**：嵌入博客、导出网页
- **建议优先级**：P3

### 文本格式化工具
- **功能**：去除多余空格、统一换行符、删除空行、大小写转换
- **使用场景**：清理复制的文本、规范格式
- **建议优先级**：P3

## 📊 数据处理类

### JSON格式化/验证
- **功能**：输入JSON字符串，自动格式化、语法验证、错误提示
- **使用场景**：调试代码、查看API响应、验证配置文件
- **建议优先级**：P1

### CSV转表格
- **功能**：导入CSV文件或文本，转换为HTML表格展示，支持排序、筛选
- **使用场景**：快速查看数据、简单的数据分析
- **建议优先级**：P2

### 表格生成器
- **功能**：可视化创建表格，设置行列数、合并单元格，导出为HTML/Markdown/CSV
- **使用场景**：快速制作表格、生成文档
- **建议优先级**：P2

### Base64编解码
- **功能**：文本/图片的Base64编码和解码
- **使用场景**：数据传输、图片嵌入
- **建议优先级**：P3

### URL编解码
- **功能**：URL参数的编码和解码
- **使用场景**：处理链接、调试网址参数
- **建议优先级**：P3

### 进制转换器
- **功能**：十进制、二进制、八进制、十六进制相互转换
- **使用场景**：编程辅助、数学学习
- **建议优先级**：P3

### 正则表达式测试器
- **功能**：输入正则表达式和测试文本，高亮匹配结果
- **使用场景**：调试正则、学习正则表达式
- **建议优先级**：P3

## 🎓 教学辅助类

### 倒计时器/正计时器
- **功能**：设置倒计时时间，全屏显示，时间到时提醒；或正计时功能
- **使用场景**：考试计时、课堂活动、番茄钟
- **建议优先级**：P1

### 随机点名器
- **功能**：导入学生名单，随机抽取一个或多个学生，支持动画效果
- **使用场景**：课堂提问、公平选人
- **建议优先级**：P1

### 随机分组工具
- **功能**：导入学生名单，设置组数，自动随机分组
- **使用场景**：小组活动、团队分配
- **建议优先级**：P2

### 抽奖转盘
- **功能**：输入奖项名称，点击旋转，随机抽取奖项，带动画效果
- **使用场景**：课堂互动、活动抽奖
- **建议优先级**：P2

### 选择题生成器
- **功能**：输入题目和选项，自动生成选择题卡片，支持打印
- **使用场景**：快速制作测试题、课堂小测验
- **建议优先级**：P3

### 成绩分段统计
- **功能**：输入成绩列表，自动统计各分段人数、平均分、最高分、最低分
- **使用场景**：分析考试成绩、了解班级情况
- **建议优先级**：P3

### 拼音标注工具
- **功能**：输入中文文本，自动标注拼音
- **使用场景**：小学语文教学、生字学习
- **技术参考**：pinyin库
- **建议优先级**：P3

### 古诗词格式排版
- **功能**：输入古诗词文本，自动排版为竖排、居中格式
- **使用场景**：制作古诗词课件、导出图片
- **建议优先级**：P3

## 🔧 实用工具类

### 二维码生成器
- **功能**：输入文本或URL，生成二维码，支持下载图片
- **使用场景**：分享链接、制作签到码
- **技术参考**：qrcode.js
- **建议优先级**：P1

### 颜色选择器
- **功能**：拾取颜色，显示HEX/RGB/HSL值，支持调色盘、渐变色生成
- **使用场景**：设计辅助、选择配色
- **建议优先级**：P2

### 单位换算器
- **功能**：长度、重量、面积、温度等常见单位相互转换
- **使用场景**：日常换算、教学演示
- **建议优先级**：P2

### 日期计算器
- **功能**：计算两个日期之间的天数、工作日，或在某日期基础上加减天数
- **使用场景**：计划安排、倒数日
- **建议优先级**：P2

### 密码生成器
- **功能**：生成随机密码，可设置长度、字符类型（大小写、数字、符号）
- **使用场景**：创建安全密码
- **建议优先级**：P2

### 图片压缩工具
- **功能**：上传图片，压缩文件大小，预览压缩效果，下载压缩后图片
- **使用场景**：减小图片体积、优化存储
- **技术参考**：浏览器Canvas API
- **建议优先级**：P2

### 图片裁剪工具
- **功能**：上传图片，自由裁剪，调整尺寸，下载裁剪后图片
- **使用场景**：制作头像、调整图片比例
- **技术参考**：Cropper.js
- **建议优先级**：P3

### 文件格式转换
- **功能**：图片格式转换（PNG↔JPG↔WebP）、视频格式转换等
- **使用场景**：格式兼容、压缩优化
- **技术参考**：浏览器API、FFmpeg.js
- **建议优先级**：P3

### 文本朗读工具
- **功能**：输入文本，使用浏览器TTS朗读，支持语速调节
- **使用场景**：辅助阅读、语言学习
- **技术参考**：Web Speech API
- **建议优先级**：P3

### 番茄钟
- **功能**：25分钟工作+5分钟休息，循环计时，时间到提醒
- **使用场景**：时间管理、专注工作
- **建议优先级**：P3

### 记事本
- **功能**：简单的文本编辑器，自动保存到浏览器LocalStorage
- **使用场景**：快速记录、临时笔记
- **建议优先级**：P3

## 📝 实现建议

### 开发策略
1. **优先实现P1工具** - 覆盖最常见的使用场景
2. **评估复杂度** - 简单工具优先（如倒计时器），复杂工具延后（如思维导图）
3. **考虑复用** - 能复用现有代码的优先（如Markdown编辑器复用预览功能）
4. **用户反馈驱动** - 根据用户使用频率决定后续开发顺序

### HTML工具
以上工具中，很多可以作为独立的HTML文件开发，然后直接上传到"常用工具"模块，无需集成到项目代码中。这样更灵活，也便于快速扩充工具库。
