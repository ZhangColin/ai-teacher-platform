### 迭代2：后台管理 - 待规划

#### 后台管理界面
**优先级**: P1  
**依赖**: 当前迭代完成

**核心功能**：
- [ ] 工具管理页面
  - [ ] 工具列表展示（按分类、类型筛选）
  - [ ] 添加内置工具（配置路由路径、名称、描述等）
  - [ ] 上传HTML工具（上传文件、配置信息）
  - [ ] 编辑工具信息（名称、描述、分类、图标等）
  - [ ] 删除工具（含确认提示）
  - [ ] 工具排序（拖拽调整顺序）
  - [ ] 工具可见性控制（启用/禁用）

- [ ] 分类管理页面
  - [ ] 分类列表展示
  - [ ] 创建新分类
  - [ ] 编辑分类信息（名称、图标）
  - [ ] 删除分类（检查是否有关联工具）
  - [ ] 分类排序（拖拽调整顺序）

**技术约束**：
- HTML文件存储路径规划
- 文件大小限制（建议：单个HTML文件 < 5MB）
- 支持的图标格式（PNG、SVG、JPEG）

**验收标准**：
- 管理员可以完整管理工具和分类（增删改查）
- 操作有明确反馈（成功/失败提示）
- 删除操作有二次确认
- 上传的HTML文件在前台正常运行

## 📊 优先级说明

- **P0** - 阻塞性问题，必须立即解决
- **P1** - 高优先级，影响核心功能或用户体验
- **P2** - 中优先级，重要但不紧急
- **P3** - 低优先级，可以延后处理
