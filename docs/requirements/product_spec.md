## 1. 项目概述

### 1.1 平台定位
一个集成AI能力体验、成果展示和实用工具的综合性平台，旨在：
- 让用户体验多种AI能力（文生文、文生图、AI编程、智能体等）
- 展示AI产生的优质成果（教学案例、编程作品、创意作品）
- 提供AI相关和通用的实用工具

### 1.2 技术架构
- **前端**: Vue 3 + TypeScript + Vite + Tailwind CSS
- **后端**: FastAPI + Python 3.10+
- **AI能力**: 基于大语言模型API（优先Kimi/DeepSeek）

### 1.3 项目现状
- **原有功能**: AI智能备课平台（教案生成、课件生成、图表生成）
- **当前状态**: 原有功能封存，开启全新开发
- **复用资源**: 前后端架构、双栏布局组件、多轮对话逻辑

### 1.4 当前阶段目标
- **产出物**: UI设计稿 + 功能模块规划文档
- **实现方式**: 基于设计稿在IDX环境中实现
- **优先级**: 先完成UI设计，再逐个实现功能模块

## 3. MVP范围定义

### 3.1 第一阶段核心功能

#### ⭐ AI提示词向导（优先级最高）
**功能描述**：帮助用户将模糊需求转化为清晰、结构化的AI提示词

**核心特性**：
- 多轮对话澄清需求
- 智能引导式提问
- 实时生成提示词预览
- 支持修改和优化
- 一键导出/复制

**参考对象**：现有教案生成器的交互模式（左侧对话，右侧预览）

**详细规格**：见 `ai_prompt_wizard_spec.md`

### 3.2 基础展示功能
- 成果展示区：静态文件展示（从固定目录读取）
- 工具区：单页工具嵌入展示

### 3.3 暂不实现
- 用户登录/注册
- 积分体系
- 文生音视频
- 数据库存储

## 4. 技术约束说明

### 4.1 大模型选择
- **当前**: Kimi API（或DeepSeek）
- **原因**: 项目已集成，可直接复用
- **未来**: 支持切换多种模型（OpenAI、Claude等）

### 4.2 存储方案
- **当前阶段**: 文件系统存储
  - 成果文件：存放在项目固定目录
  - 工具源码：以HTML单文件形式存储
- **未来规划**: 
  - 引入数据库（MySQL/PostgreSQL）
  - OSS对象存储（阿里云/AWS S3）

### 4.3 前端路由
- **决策方**: UI设计师根据设计稿确定
- **要求**: 清晰的导航结构，良好的用户体验
- **参考**: SPA单页应用，Vue Router管理

### 4.4 系统提示词
- **预设场景**: 每个AI能力模块预设优化的系统提示词
- **用户透明**: 用户无需了解提示词细节，直接体验功能
- **可配置**: 后台可调整优化（开发时讨论）

### 4.5 响应式设计
- **优先**: 桌面端体验
- **兼容**: 移动端基础适配
- **优化**: 二期进行移动端深度优化
