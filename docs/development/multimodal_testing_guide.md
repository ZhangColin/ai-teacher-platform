## 📋 测试前准备

### 1. 服务启动状态

确认前后端服务都已启动：

```bash
# 前端服务
cd frontend && npm run dev
# 访问: http://localhost:5173/

# 后端服务
cd backend && python3 -m uvicorn src.main:app --reload --port 8000
# 访问: http://127.0.0.1:8000
```

### 2. 测试账号

使用以下账号登录系统：

- **用户名**: `admin`
- **密码**: `HcyAdmin@2026`
- **角色**: 管理员

如果账号不存在，运行创建脚本：

```bash
cd backend
python3 scripts/create_initial_user.py
```

### 3. 环境变量检查

确认后端 `.env` 文件包含 GLM API 配置：

```env
# GLM API配置（文生图）
GLM_API_KEY=your_glm_api_key
GLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
GLM_MODEL=cogview-3
```

⚠️ **重要**: 没有配置 GLM API Key 将无法测试真实的图片生成功能

## 🔧 调试技巧

### 1. 查看后端日志

```bash
# 终端输出会显示所有请求日志
tail -f /path/to/backend/logs/app.log
```

### 2. 查看浏览器控制台

打开浏览器开发者工具（F12）：
- **Console**: 查看错误和日志
- **Network**: 查看 API 请求和响应
- **Vue DevTools**: 查看组件状态

### 3. 测试 API 接口

```bash
# 登录获取 Token
curl -X POST http://127.0.0.1:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"account":"admin","password":"HcyAdmin@2026"}'

# 使用 Token 调用生成接口
curl -X POST http://127.0.0.1:8000/api/v1/tools/image_gen/generate-media \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"message":"一只可爱的小猫","size":"1024x1024","count":1}'

# 查询任务状态
curl -X GET http://127.0.0.1:8000/api/v1/tasks/TASK_ID \
  -H "Authorization: Bearer YOUR_TOKEN"
```
