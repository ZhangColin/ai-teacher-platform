## 🐛 发现并修复的 Bug

在测试过程中发现并修复了 3 个重要的 Bug：

### 1. routers/users.py:140 - 错误的服务实例化
**问题**: 直接实例化 UserService 而不是使用依赖注入
```python
# Before (bug):
user_service = UserService()

# After (fixed):
user_service = get_user_service()
```

### 2. models.py:403 - 错误的类型定义
**问题**: CreateUserResponse.user 字段类型错误
```python
# Before (bug):
user: UserInfo = Field(..., description="新创建的用户信息")

# After (fixed):
user: UserListItem = Field(..., description="新创建的用户信息")
```

### 3. ChatArea.vue - 缺少 messages 属性传递
**问题**: ChatPanel 没有接收到 messages 数据
```vue
<!-- Before (bug): -->
<ChatPanel />

<!-- After (fixed): -->
<ChatPanel :messages="sessionStore.messages" />
```
